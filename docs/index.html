Tessera

Run Linux desktop apps on Android. Firefox, GIMP, VS Code, LibreOffice, all of Debian and 2,800+ Flathub apps, each as its own Android app, on your phone's GPU and in your phone's colors. No terminal, no VNC, root optional.

What it does

Flathub on Android

2,800+ Flathub apps from a phone-style store, without root, bubblewrap or user namespaces, and still on the GPU.

One Linux app, one Android app

Every Linux app and window gets its own Recents card, and you can pin it to your home screen.

Desktop-class GPU

OpenGL 4.6 and Vulkan on Adreno through Tessera's own Mesa Turnip and Zink build.

Material You for Linux

GTK, libadwaita, Qt, LibreOffice and Firefox follow your wallpaper's colors and dark mode, live.

A full desktop mode

One tap for a Linux desktop: movable, snapping windows, a dock, a Start menu, desktop icons and drag and drop.

A sandbox per app

Folders, network, sound, USB and root are granted one by one, like Android permissions. PRoot or chroot.

Get started

  1. Download the APK from GitHub releases, or add the repo to Obtainium for updates.
  2. Open Tessera and let it set up Debian (a one-time download).
  3. Install apps from the store, or tap Desktop for a whole Linux desktop.

Tessera needs Android 7 or newer on an arm64 phone and a few GB of free storage. GPU acceleration needs an Adreno GPU. It's an alpha: report bugs on GitHub.

Tessera is free software under the GPLv3. Built on Termux:X11, PRoot, Mesa and Debian.
